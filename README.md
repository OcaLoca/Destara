# Destara 🗡️📖

**Destara** is a cross-platform interactive gamebook developed in **Unity**, combining a rich branching narrative with tactical combat mechanics, strategems, and puzzles.

## 👥 Team & Leadership

* **Team Size:** 10 Members (Game Designers, Narrative Designers, 2D/3D Artists, Developers).
* **Role:** Lead Developer / Project Manager — Directly managed and led the 10-person team, overseeing the development roadmap, sprint planning, task delegation, and technical integration between C# architecture and artistic/narrative assets.

## 🛠️ Tech Stack

* **Game Engine:** Unity
* **Language:** C#
* **Deployment:** WebGL / PC / Mobile
* **Architecture:** Scriptable Objects, Event-Driven Systems

## 🎮 Key Features

* **Dynamic Narrative:** Multi-branching storyline where player choices directly impact the protagonist's fate and narrative outcome.
* **Tactical Combat System:** Engagement mechanics based on character stats, equipment, and strategic choices.
* **Strategems & Puzzles:** Inventory mechanics, riddles, and tactical decision-making to overcome encounters without relying solely on brute force.
* **Character Sheet:** Real-time tracking of hit points, inventory, special abilities, and story progression.
